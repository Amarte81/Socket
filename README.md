# Java Sockets, Sistemi Client-Server & Microservizi

Corso interattivo ed applicazione web dedicata allo studio e alla sperimentazione con le Socket in Java, le architetture Client-Server e i Microservizi.

## Contenuti

- Architettura Client-Server (modelli TCP e UDP)
- Programmazione con Java Socket e ServerSocket
- Gestione della concorrenza e Multi-threading
- Sistemi distribuiti e introduzione ai Microservizi
- Esercizi pratici ed esempi di codice interattivi

## Utilizzo

Apri `index.html` in qualsiasi browser web moderno per visualizzare ed interagire con il corso.
